# Connect-Consulting Company Ltd website prototype

A responsive static website for client review.

## Pages

- `index.html` — Home
- `about.html` — About Us
- `services.html` — Services
- `insights.html` — News and articles
- `contact.html` — Let’s Talk
- `site.css` — Shared styling

Open `index.html` in a browser to preview the site. The placeholder photography and web fonts load from external services and require an internet connection.

This is a prototype. The illustrative service scenarios and any profile details flagged for confirmation should be reviewed with the business owner before public release.
